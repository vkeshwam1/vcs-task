# VCS Task

1. Created a directory with script files, ran `git init`, added a GitHub remote and pushed to `main`.
2. Merge: `feature-merge` merged into `main` with a merge commit.
3. Rebase: `feature-rebase` rebased onto `main`, then fast-forward merged.
4. Stash: `git stash`, `git stash list` and `git stash pop` on uncommitted changes.

Screenshots are in the `screenshots/` folder.
